# FitAI — Frontend Client (React + Vite + TailwindCSS)

Клиентская часть приложения FitAI на **React 19**, **Vite 8**, **Tailwind CSS v4** и **MediaPipe Pose**.

## 🚀 Быстрый запуск

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev

# 3. Сборка продакшн-бандла
npm run build
```

Приложение будет доступно по адресу: `http://localhost:5173`.
Бэкенд по умолчанию ожидается на: `http://localhost:8000`.
