## 🎯 О Проекте

**FitAI** решает ключевую проблему домашних тренировок — **отсутствие контроля техники и персонального тренера**. Приложение использует камеру смартфона или ноутбука, в реальном времени анализирует биомеханику движения по 33 анатомическим точкам тела с помощью ИИ, считает только идеальные повторы, предотвращает травмы в **«Режиме Ошибка»** и ведет голосовой коучинг без задержек и отправки видео на сервер.

Все персональные данные, планы тренировок, история подходов и баланс токенов сохраняются в локальной реляционной базе данных **SQLite**.

## ✨ Ключевой Функционал

### 1. 🏋️ Библиотека Упражнений с AI-Контролем (MediaPipe Pose)
* **Классические приседания (Squats):** Трекинг угла коленных суставов (строгий контроль глубины до 90°) и угла спины (>145°, защита от заваливания вперед).
* **Планка (Plank hold):** Контроль ровной линии тела (плечо – таз – голеностоп). Таймер фиксирует только секунды непрерывного идеального удержания.
* **Классические отжимания (Push-ups):** Контроль угла локтей (до 90° в нижней точке) и ровной линии корпуса без провисания поясницы.
* **Jumping Jacks (Прыжки):** Динамический кардио-трекинг синхронного разведения рук и ног в воздухе.
* **Подъемы рук для осанки (Arm Raises):** Контроль траектории рук выше плеч для выпрямления грудного отдела.
* **«Режим Ошибка» (Red Error Mode):** Скелет мгновенно подсвечивается красным цветом при нарушении техники, сопровождаясь подсказкой об ошибке.

### 2. 🎙️ Голосовой ИИ-Ассистент (Web Speech API)
* Голосовой инструктаж перед началом каждого упражнения (правильная стойка, углы, дыхание).
* Обратная связь во время тренировки («Отличная глубина!», «Держите спину ровнее», «Подход завершен!»).
* Автоматический старт упражнения после завершения озвучки инструкции.
* Быстрый тумблер звука в навигационной панели и на экране тренировки.

### 3. 🗓️ Умный Стартовый Экран & План на Неделю
* **Безопасный старт:** Веб-камера **не включается автоматически** при входе, сохраняя приватность пользователя.
* **Приветственная карточка:** Персональное обращение «С возвращением, [Имя]! 👋» с текущим балансом токенов и стриком дней.
* **Интерактивный календарь:** Наглядное расписание на 7 дней недели (Пн–Вс) с ярким выделением сегодняшнего дня (**«Сегодня»**), активного тренировочного дня и дней восстановления.
* **Список упражнений дня:** Карточки с целевыми повторами, секундами удержания, числом сетов, временем отдыха и темпом.
* **Последовательный запуск:** Нажатие «Начать тренировку» последовательно открывает модалку с инструкцией и озвучкой, а затем бесшовно запускает камеру.

### 4. 🏆 Реальный Глобальный Лидерборд
* Рейтинговая таблица строится **строго из реальных пользователей** SQLite базы данных (никаких синтетических ботов).
* Расчет очков (XP) по формуле: Регулярность (стрик дней) + Точность ИИ-техники (%) + Объем выполненных повторений + Токены.
* Адаптивный пьедестал почета (1, 2 и 3 места) и ранги: *Новичок*, *Атлет*, *Мастер*, *Легенда*.

### 5. 🛍️ Магазин & Система Аватарок
* **3 бесплатные базовые аватарки:** 🦊 *Лис-Спринтер*, 🤖 *Кибер-Атлет*, 🦁 *Лев-Чемпион*.
* **3 премиум арт-аватара за FIT-токены:** «Кибер-Неон» (100 FIT), «Фитнес-Воин» (200 FIT), «Титаниум» (300 FIT).
* **Смена аватара в профиле:** Модальное окно в личном кабинете с мгновенным надеванием доступных аватаров и покупкой новых прямо из профиля.

## 🚀 Пошаговый Запуск

### Требования:
* **Python** 3.10 или выше
* **Node.js** 18.x или выше (с менеджером пакетов `npm`)
* Веб-камера (для AI-трекинга движений)

---

### Шаг 1: Запуск Бэкенда (FastAPI)

1. Откройте терминал и перейдите в директорию `backend`:
   ```bash
   cd backend
   ```

2. Установите зависимости Python:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите сервер FastAPI:
   ```bash
   uvicorn main:app --reload --port 8000
   ```

* Сервер бэкенда будет доступен по адресу: **`http://localhost:8000`**
* Интерактивная документация Swagger UI: **`http://localhost:8000/docs`**

---

### Шаг 2: Запуск Фронтенда (React + Vite)

1. Откройте второй терминал и перейдите в директорию `frontend`:
   ```bash
   cd frontend
   ```

2. Установите зависимости npm (при первом запуске):
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

* Приложение откроется в браузере по адресу: **`http://localhost:5173`**

---

### 💡 Быстрый Запуск из Корня Проекта

## 🗄️ База Данных и Автоматические Миграции

* **СУБД:** Локальная реляционная база **SQLite** (файл `backend/database.db`).
* **ORM:** **SQLAlchemy 2.0+** с автоматическим созданием всех таблиц при первом старте сервера:
  ```python
  Base.metadata.create_all(bind=engine)
  ```
  Никаких ручных миграций или SQL-скриптов накатывать не нужно — таблицы, индексы и внешние ключи инициализируются «из коробки».

---

### 📋 Полная Схема Таблиц Реляционной БД:

#### 1. `users` — Профили и настройки пользователей
* `id` (`Integer`, Primary Key) — уникальный идентификатор пользователя
* `email` (`String`, Unique, Not Null, Index) — email для авторизации
* `username` (`String`, Not Null) — отображаемое имя атлета
* `password_hash` (`String`, Not Null) — безопасно захэшированный пароль (SHA-256)
* `tokens` (`Integer`, Default: 0) — заработанные FIT-токены за тренировки
* `streak` (`Integer`, Default: 1) — стрик дней непрерывных тренировок
* `active_avatar` (`String`, Default: `'emoji_fox'`) — текущий активный аватар пользователя
* `is_onboarded` (`Boolean`, Default: `False`) — пройден ли первичный опросник
* `is_voice_enabled` (`Boolean`, Default: `True`) — состояние голосового ассистента
* `last_workout_date` (`String`, Nullable) — дата последней тренировки (формат YYYY-MM-DD)
* `goal` (`String`, Default: `'muscle'`) — фитнес-цель (`'loss'`, `'posture'`, `'muscle'`)
* `level` (`String`, Default: `'intermediate'`) — уровень подготовки (`'beginner'`, `'intermediate'`, `'advanced'`)
* `frequency` (`Integer`, Default: 3) — число тренировок в неделю (1–7)
* `created_at` (`DateTime`) — дата и время регистрации

#### 2. `workout_plans` — Персональные планы тренировок
* `id` (`Integer`, Primary Key) — уникальный ID плана
* `user_id` (`Integer`, Foreign Key ➔ `users.id`, Cascade Delete) — ID владельца
* `goal` (`String`, Not Null) — цель плана
* `level` (`String`, Not Null) — уровень сложности
* `frequency` (`Integer`, Not Null) — тренировочные дни
* `plan_data_json` (`Text`, Not Null) — структура недельного плана в JSON (упражнения, повторы, подходы, отдых)
* `updated_at` (`DateTime`) — дата генерации/обновления плана

#### 3. `user_avatars` — Инвентарь купленных аватарок
* `id` (`Integer`, Primary Key) — уникальный ID записи
* `user_id` (`Integer`, Foreign Key ➔ `users.id`, Cascade Delete) — ID покупателя
* `avatar_id` (`String`, Not Null) — ID аватара (`'avatar_icon1'`, `'avatar_icon2'`, `'avatar_icon3'`)
* `created_at` (`DateTime`) — дата разблокировки

#### 4. `workout_history` — История выполненных подходов и рейтинг
* `id` (`Integer`, Primary Key) — уникальный ID записи
* `user_id` (`Integer`, Foreign Key ➔ `users.id`, Cascade Delete) — ID атлета
* `exercise` (`String`, Not Null) — название упражнения
* `reps` (`Integer`, Not Null) — количество зачтенных повторов / секунд удержания
* `accuracy` (`Integer`, Not Null) — точность техники в процентах (%)
* `tokens_earned` (`Integer`, Not Null) — начисленные токены за подход
* `created_at` (`DateTime`) — дата и время выполнения

---

### 📊 Сводная Таблица Сущностей:

| Таблица | Основные Поля | Назначение | Связи (Foreign Keys) |
| :--- | :--- | :--- | :--- |
| **`users`** | `id`, `email`, `username`, `tokens`, `streak`, `active_avatar`, `goal`, `level` | Аккаунты атлетов, стрик, баланс, аватар | Родительская таблица |

| **`workout_history`** | `id`, `user_id`, `exercise`, `reps`, `accuracy`, `tokens_earned` | История подходов и расчет лидерборда | `user_id` ➔ `users.id` |

## ⚙️ Переменные Окружения (.env)

По умолчанию проект работает «из коробки» на локальных портах `8000` и `5173` без обязательного создания `.env`.

При необходимости кастомизации скопируйте шаблоны:


## 🛡️ Безопасность и Архитектурные Решения

1. **Приватность видеопотока:** Веб-камера обрабатывается на клиенте через WebAssembly/GPU (MediaPipe Pose). Ни одного кадра видео не отправляется на сервер или в сторонние облака.
2. **Безопасная авторизация:** Пароли хешируются с использованием SHA-256 + Salt. Запросы к API защищены токенами Bearer.
3. **Отсутствие внешних платных API:** Все функции (ИИ-распознавание, голосовой ассистент, генерация программ, хранилище) работают на 100% автономно и бесплатно.
